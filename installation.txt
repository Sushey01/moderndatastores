/* -
add mongodb server bin folder to environment variable path  (so that we can use mongod command in any terminal path)
    C:\Program Files\MongoDB\Server\7.0\bin
    mongod command only 
            works on  the folder where mongod.cfg exist   (cfg => configuration)
            generally on C:\Program Files\MongoDB\Server\7.0\bin  path
    To work mongod in any path of terminal 
        search edit environment variable 
        under advance >>edit environment variable>> under system variables(section)>>find path
        select path and click edit 
        add new and paste C:\Program Files\MongoDB\Server\7.0\bin
        click ok (3 times) on different tab  (it is the common mistake)
    check 
        open cmd (any terminal)
        type mongod --version
        if it show version then mongod is working
add mongodb tools bin folder to environment variable path (so that we can use mongodump,mongorestore command in any terminal path)
    C:\Program Files\MongoDB\Tools\100\bin

/*
